# XI-1 MIPA Teknik — Website Kelas

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `website-kelas-xi1-mipa-teknik`.
3. Klik dua kali `index.html`.
4. Website akan terbuka di browser.

## Cara edit
- Tulisan/nama/tagline: buka `index.html`.
- Warna, ukuran, layout: buka `style.css`.
- Data siswa, tugas, pencarian, dark mode: buka `script.js`.
- Foto: nanti bisa dimasukkan ke folder `images`.

Tips: gunakan VS Code supaya lebih mudah mengedit file.
